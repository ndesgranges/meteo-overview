I like the overview MSN weather offers. I've been using a script that screenshot
the `div` I liked to display it in home assistant in an image card.

Later, I built my own weather backend, using multiple sources, and I made a
custom integration to integrate it as a weather provider in home assistant.
From there, it was the logical path, just to make this custom card with the look
I wanted and level optimization of the information.


## Installation


[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ndesgranges&repository=meteo-overview&category=plugin)

OR

1. Install HACS if you don't have it already
2. Open HACS in Home Assistant
3. On the top right side, click the three dot and click `Custom repositories`
4. Where asked for a URL, paste the link of this repository:
https://github.com/ndesgranges/meteo-overview
1. Where asked for a type, select `dashboard`
2. Click the download button. ⬇️
